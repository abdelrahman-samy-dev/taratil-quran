## المميزات

### المصحف
- **خط مصحف المدينة الأصلي** (طبعة مجمع الملك فهد، خطوط QCF v2) بدل الصور: حاد في أي حجم، وخفيف، ويتلوّن مع الوضع الليلي.
- صفحتان متجاورتان على الشاشات العريضة كالمصحف المطبوع، والسحب لتقليب الصفحات على الجوال.
- اضغط على أي آية: **استمع من هنا، كرّرها للحفظ، التفسير الميسر، نسخ، مشاركة، علامة** (حفظ / تدبر / مراجعة).
- **متابعة التلاوة:** تظليل الآية التي يقرؤها القارئ وتقليب الصفحات معه.
- فهرس للسور والأجزاء والعلامات، والانتقال لأي صفحة، وألوان ورقية مريحة مع تعتيم للقراءة الليلية.
- **الورد الحقيقي:** الصفحة تُحسب مقروءة بعد بقائك عليها، لا بمجرد فتحها.

### الاستماع
- أكثر من ٢٠٠ قارئ وروايات متعددة (mp3quran.net).
- **تظليل دقيق للآيات** لأكثر من ١١٠ تلاوة من مواضع الآيات الحقيقية في التسجيل، وتقديري لبقية التلاوات.
- التحكم من شاشة القفل والسماعات، سرعات التلاوة، تكرار السورة أو الآية، مؤقت نوم يخفت الصوت تدريجيًا.
- **تحميل السور للاستماع بدون إنترنت**، ومتابعة الاستماع من حيث توقفت.

### وأيضًا
- **التفسير ووضع التسميع** (الميسر، الجلالين، القرطبي، البغوي، الوسيط، تنوير المقباس).
- **البحث في القرآن** بالكلمة أو برقم السورة والآية.
- **الأذكار** بعدّاد لكل ذكر وحفظ تقدم اليوم، و**السبحة** مع تسبيح ما بعد الصلاة.
- **مواقيت الصلاة تُحسب على جهازك** (تعمل بدون إنترنت) مع اختيار طريقة الحساب، و**اتجاه القبلة** بالبوصلة.
- **إذاعات القرآن** المباشرة، و**الأحاديث** من كتب السنة مع البحث داخل الكتاب.
- **الورد والختمة:** هدف يومي، خطة ختمة بعدد أيام، سلسلة أيام متتالية، رسوم بيانية، وإنجازات.
- نسخة احتياطية لبياناتك واستعادتها، وثلاثة أوضاع للمظهر (فاتح، داكن، أسود AMOLED).

## التقنيات

| الجانب | الاختيار |
| --- | --- |
| الواجهة | [Preact](https://preactjs.com) + [Signals](https://preactjs.com/guide/v10/signals) + TypeScript (strict) |
| البناء | [Vite](https://vite.dev)، كل شاشة في ملف منفصل يُحمَّل عند فتحها |
| العمل بدون إنترنت | Service Worker عبر Workbox (`src/sw.ts`) |
| المواقيت والقبلة | [adhan-js](https://github.com/batoulapps/adhan-js) |
| الاختبارات | Vitest (منطق التطبيق) + Playwright (اختبارات المتصفح) |

### هيكل المشروع

```text
src/
  app.tsx              المسارات (كل شاشة تُحمَّل عند الحاجة)
  layout/              الهيكل: القائمة، الشريط السفلي، المشغل المصغّر والكامل
  audio/               محرك الصوت، القراء، مواضع الآيات، التحميل للاستماع دون اتصال
  quran/               بيانات القرآن (السور، النص، صفحات المصحف)
  state/               التفضيلات، التقدم والورد، ترحيل بيانات الإصدار السابق
  features/<الشاشة>/   كل شاشة بمكوناتها وتنسيقها
  ui/                  مكونات مشتركة (النوافذ، الأيقونات، العناصر)
  lib/                 أدوات (التخزين، العربية، التنسيق، الشبكة)
  sw.ts                Service Worker
public/data/           بيانات ثابتة: نص كل سورة، فهرس البحث، تخطيط صفحات المصحف الـ٦٠٤
scripts/               توليد البيانات والأيقونات
tests/                 unit (Vitest) و e2e (Playwright)
```

### التشغيل محليًا

```bash
npm install
npm run dev          # http://localhost:5180
npm test             # اختبارات المنطق
npm run build        # نسخة الإنتاج في dist/
npm run e2e          # اختبارات المتصفح على نسخة الإنتاج
```

- `npm run data:quran` يعيد توليد بيانات القرآن من Quran.com API (لا يحتاجه التطبيق وقت التشغيل).
- `npm run icons` يعيد توليد أيقونات التطبيق من `public/icons/icon.svg`.

النشر على Vercel تلقائي (`vercel.json`): يبني المشروع ويعيد توجيه المسارات إلى التطبيق.
